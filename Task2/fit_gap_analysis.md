# Fit/Gap-анализ: онлайн-аукцион алмазов в "Diamond Universe"

## Список систем

* ИС "Алмазы" (**существующая**) (основной бизнес)  

  | Функциональность | Комментарий |
  | -- | -- |
  | (**сущ.**) планирование работ | **без изменений**. Используется для планирования логистики |
  | (**сущ.**) присвоение идентификаторов | **без изменений**. Применяется для учёта алмазов в процессе |
  | (**сущ.**) подготовка ведомостей | **без изменений**. Ведомости используются для сопровождения |
  | (**нов.**) отбор алмазов для цифрового аукциона | Добавить статус и признак "участвует в онлайн-аукционе". Автоматизировать формирование списка лотов |

* ИС "Аукцион" (**существующая**) (основной бизнес)  

  | Функциональность | Комментарий |
  | -- | -- |
  | (**сущ.**) проведение офлайн аукциона | **без изменений**. Текущий процесс сохраняется |
  | (**нов.**) проведение онлайн аукциона | Добавить модуль онлайн-торгов, возможность регистрации покупателей, механизм ставок |
  | (**нов.**) публикация данных для клиентов | Настроить витрину лотов с ограничением доступа по ролям |
  | (**нов.**) отображение оцифрованных характеристик камней | Разработать карточку лота и интеграцию с данными из ИС "Лаборатория" |

* ИС "Логистика" (**существующая**) (внутренняя обеспечивающая система)  

  | Функциональность | Комментарий |
  | -- | -- |
  | (**сущ.**) перевозка алмазов по стране и за границу | **без изменений** |
  | (**сущ.**) доставка алмазов покупателям | **без изменений** |
  | (**нов.**) отправка алмазов в лабораторию | Добавить новый тип маршрута «Лаборатория оцифровки» и статусы контроля |
  | (**нов.**) возврат алмазов в офис после оцифровки | Добавить статусы приёмки и сверку с реестром отправленных камней |

* ИС "Бухгалтерия" (**существующая**) (внутренняя обеспечивающая система)  

  | Функциональность | Комментарий |
  | -- | -- |
  | (**сущ.**) ведение контрактов | **без изменений**. Используется для договоров с покупателями |
  | (**сущ.**) актирование и оплата услуг компаний-перевозчиков | **без изменений** |
  | (**нов.**) актирование и оплата услуг лаборатории по оцифровке | Добавить учёт услуг оцифровки и привязку к реестрам камней |

* ИС "Лаборатория" (**новая**) (внешняя обеспечивающая система)  

  | Функциональность | Комментарий |
  | -- | -- |
  | (**нов.**) оцифровка алмазов | Обеспечить процесс фото/видеофиксации по утверждённым методикам, получение отчетов со специализированных измерительных приборов |
  | (**нов.**) формирование подробного описания камней | Необходимо согласовать единый формат данных |
  | (**нов.**) передача оцифрованного снимка алмазов | Реализовать интеграцию через защищённый канал (SFTP/VPN). Обеспечить контроль целостности (контрольные суммы) |

* Облачные сервисы (**новая**) (внешняя обеспечивающая система)  

  | Функциональность | Комментарий |
  | -- | -- |
  | (**нов.**) публикация данных для клиентов | Выбрать провайдера, согласовать SLA/SLO, настроить ролевой доступ для покупателей |

## Список интеграций

| Интеграция | Как реализована | Какие данные передаются |
| -- | -- | -- |
| (**сущ.**) ИС "Алмазы" → ИС "Логистика" | автоматически | реестры отобранных алмазов, маршруты перевозки |
| (**сущ.**) ИС "Логистика" → ИС "Бухгалтерия" | автоматически | акты выполненных работ, счета на оплату перевозок |
| (**сущ.**) ИС "Аукцион" → ИС "Бухгалтерия" | автоматически/вручную (не уточнено) | результаты торгов, суммы сделок для учета |
| (**нов.**) ИС "Лаборатория" → ИС "Аукцион" | файлами вручную (на первом этапе),<br>автоматически (в целевой) | цифровые паспорта камней, фото, видео, оценочные характеристики, метрики |
| (**нов.**) ИС "Лаборатория" → ИС "Бухгалтерия" | файлами вручную (на первом этапе),<br>автоматически (в целевой) | акты об оказании услуг оцифровки, счета на оплату услуг |
| (**нов.**) ИС "Аукцион" → Облачные сервисы | автоматически (API) | данные для публикации лотов, итоги аукциона |
